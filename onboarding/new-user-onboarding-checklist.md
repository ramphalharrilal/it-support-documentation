# New User Onboarding Checklist

## Purpose

Use this template to coordinate secure account, device, application, and access preparation for a new employee or contractor. Adapt it to the organization's approved onboarding process.

## Request Information

- [ ] Approved onboarding request or ticket received
- [ ] User's legal and preferred name confirmed through the authorized source
- [ ] Manager, department, role, location, and start date confirmed
- [ ] Employment type and end date recorded when applicable
- [ ] Required applications, groups, shared resources, and equipment approved
- [ ] Special accessibility or remote-work requirements routed appropriately

## Account and Access

- [ ] Create the directory or identity account using the naming standard
- [ ] Assign only role-approved groups and permissions
- [ ] Assign required Microsoft 365 or other licenses
- [ ] Configure email, calendar, and approved shared resources
- [ ] Configure VPN or remote access when approved
- [ ] Enroll the user in MFA through the approved process
- [ ] Set temporary credentials according to policy
- [ ] Require password change at first sign-in when policy requires it
- [ ] Record approvals for privileged or sensitive access

## Device Preparation

- [ ] Record device asset tag, serial number, model, and assigned user
- [ ] Apply the approved operating-system image or configuration
- [ ] Install current security and operating-system updates
- [ ] Confirm disk encryption and endpoint protection are active
- [ ] Enroll the device in approved management tools
- [ ] Install role-required applications from approved sources
- [ ] Configure printers and peripherals when requested
- [ ] Confirm screen lock, firewall, and automatic update settings
- [ ] Test camera, microphone, audio, network, and charging equipment

## Validation

Use a test process that does not expose the user's password:

- [ ] Account status and license assignment verified
- [ ] MFA enrollment completed by the user
- [ ] Email and calendar tested
- [ ] Required applications launch and authenticate
- [ ] Approved file shares and collaboration sites are accessible
- [ ] VPN or remote access tested if required
- [ ] Printer or peripheral access tested if required
- [ ] No unnecessary local administrator rights assigned

## User Handoff

- [ ] Verify user identity before providing the device or initial access instructions
- [ ] Provide secure first-sign-in instructions
- [ ] Explain MFA, password, acceptable-use, and phishing-reporting expectations
- [ ] Show the user how to reach the service desk and submit a ticket
- [ ] Provide approved quick-start documentation
- [ ] Obtain equipment receipt or acknowledgement when required

## Closure

- [ ] User and manager confirm required access works
- [ ] Asset and license records updated
- [ ] Exceptions, pending access, and follow-up dates documented
- [ ] Ticket includes completed checks, approvals, and final outcome
- [ ] Onboarding request closed according to procedure

## Least Privilege Reminder

Access should match the user's approved job duties. Do not copy another employee's permissions without verification, and do not grant privileged access merely for convenience.
